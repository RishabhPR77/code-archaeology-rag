# Code Archaeologist

Ask why any code was written and get grounded, cited answers from a repository's commits, pull requests and code reviews. Bring your own Anthropic, OpenAI, Gemini, Groq or OpenRouter key.

Source code and docs: https://github.com/RishabhPR77/code-archaeology-rag

> To sign in, open the app on its own `*.hf.space` URL (the banner at the top of the app links to it).
